# Workshop: 用 Deepseek Harness 快速搭建一个端侧智能体

> DevFest 2026 Fuzhou 活动用 Repo，内含部分预制组件和预设提示词

## 使用方法

点击右上角 `Code<>` 按钮，选择 `Download ZIP` 下载当前项目的压缩包。解压到 `D:\` 内部。

使用 Deepseek Harness，新建工作区并打开解压后的文件夹。

对 Deepseek Harness 说

```plain-text
阅读 AGENTS.md 并开始构建
```

随后等待 Deepseek Harness 执行编程任务，过程将消耗 15 到 30 分钟的时间。
